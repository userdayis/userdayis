## 📂 Proyecto destacado

### 🏋️ Tone Trainer

**Tone Trainer** es una plataforma web y móvil para la gestión y seguimiento de usuarios de un gimnasio.

El proyecto busca integrar diferentes áreas del entrenamiento en una sola plataforma:

* 🏋️ Creación y seguimiento de rutinas
* 📈 Historial y progreso físico
* 🥗 Planes y seguimiento nutricional
* 💬 Comunicación entre clientes y entrenadores
* 👤 Gestión de usuarios y roles
* 📊 Reportes y seguimiento
* 🤖 Funcionalidades de asistencia mediante IA
* 🏆 Retos y funcionalidades de fidelización

El proyecto hace parte de mi proceso de aprendizaje y desarrollo en **Análisis y Desarrollo de Software**.
